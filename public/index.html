02 / Selected projects

Research and things I’ve built.

A selection of research, coursework and team projects. Each repository contains the implementation, experiment details or a walkthrough.

01Master’s thesis · Aalto University

Crowd state estimation from partial observations

Reconstructing crowd density, velocity and velocity variance when mobile robots see only part of an environment. A shared ATC evaluation compares six reconstruction methods, including Senseiver, DINCAE, 4DVarNet and EnKF, using reconstruction error and uncertainty metrics.

Python · PyTorch · State estimationResearch & evaluation ↗
02Efficient deep learning

Knowledge distillation

Experiments transferring knowledge from larger teacher networks to compact student models, including ResNet-34 and MobileNetV2. Exploring the trade-off between model size and image classification performance.

PyTorch · Model compressionCode & experiments ↗
03LLM application

Document question answering

A retrieval-augmented generation system for PDFs, text, Markdown and web pages. Documents are indexed in ChromaDB, retrieved by similarity, and used as context for Llama 3.3 through Groq, with a Streamlit interface.

04Reinforcement learning · Aalto

Learning control policies

Course exercises and a final project exploring reinforcement learning through PPO and DDPG implementations. Includes training configurations, notebooks and recorded experiment outputs.

05Robotics · KTH

Autonomous robot manipulation

A course project using ROS and Python for pick-and-place tasks, with particle filtering for robot localization. Bringing sensing, planning and robot execution together in one system.
